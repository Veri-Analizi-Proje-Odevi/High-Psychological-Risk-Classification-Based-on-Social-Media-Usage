# High-Psychological-Risk-Classification-Based-on-Social-Media-Usage
İçinde bulunduğumuz dijital çağda, dünya nüfusunun yarısından fazlasının aktif olarak kullandığı sosyal medya platformları, yalnızca birer iletişim aracı olmaktan çıkıp bireylerin günlük yaşantılarının ve sosyal kimliklerinin merkezine yerleşmiştir.
